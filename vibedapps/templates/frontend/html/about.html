About Our DApp

This is a decentralized application (DApp) built with Ethereum blockchain technology.

It allows users to interact with smart contracts on the Ethereum blockchain in a user-friendly way.

Features include:

  • Connect with MetaMask or other Web3 wallets
  • Interact with smart contracts
  • View transaction history
  • Real-time updates
